مدیریت کارگاه لیزری دربار — نسخه محلی موبایل

نصب:
۱. پیش از جایگزینی فایل‌های سایت فعلی، از آن‌ها و از اطلاعات برنامهٔ قبلی پشتیبان بگیرید.
۲. فایل‌های index.html، manifest.webmanifest، icon.svg و sw.js را در ریشهٔ مخزن GitHub Pages بارگذاری کنید.
۳. در تنظیمات مخزن، Pages را روی branch و پوشهٔ root درست تنظیم کنید.
۴. سایت را در موبایل باز کرده و از منوی مرورگر «Add to Home Screen / افزودن به صفحهٔ اصلی» را انتخاب کنید.

محدودیت‌ها:
- اطلاعات در localStorage همان مرورگر و دستگاه است؛ خودکار همگام نمی‌شود. مرتب JSON backup بگیرید.
- قفل ورود، قفل محلی ساده است و جایگزین امنیت سروری/رمزنگاری دیتابیس نیست.
- خروجی Excel به شکل CSV UTF-8 است، نه workbook چندبرگی.
- PDF از قابلیت چاپ مرورگر استفاده می‌کند. در چاپ، «ذخیره به PDF» را انتخاب و خروجی فارسی را آزمایش کنید؛ شکل‌دهی متن ممکن است به مرورگر وابسته باشد.
- قبل از جایگزینی، اطلاعات نسخهٔ قدیمی را صادر کنید؛ ساختار نسخهٔ جدید جدا است.
